inteiliDOS COMMAND REFERENCE
==========================

Commands are grouped by category. Shell commands are entered at the
inteiliShell prompt; BASIC commands are entered inside inteiliBASIC.
Aliases are listed together. <name> means a required value; [value] means
an optional value. Do not type the angle brackets or square brackets.

This reference describes commands recognized by the source code, including
placeholders. A success message from a placeholder does not mean files
were changed, a package was installed, or a backup was created.
Application keyboard shortcuts are separate from typed commands.


1. INTEILISHELL: HELP, SCREEN AND SESSION
---------------------------------------

HELP / ?
  Show shell help and command categories.

CLS / CLEAR
  Clear the screen.

HISTORY
  Display previously entered shell commands.

ABOUT
  Display inteiliDOS identification and developer information.

HELLO
  Display a greeting and a reminder about HELP.

QUIT / EXIT
  Explain that you are already in the shell. These do not shut down the OS.

SHUTDOWN
  Attempt to power off, then halt. Power-off support depends on hardware.

RESTART / REBOOT
  Attempt a reboot through the keyboard controller.


2. INTEILISHELL: SYSTEM INFORMATION AND DIAGNOSTICS
-------------------------------------------------

MEM
  Display total, used and free memory.

SYSINFO
  Display OS, architecture, shell, filesystem, memory and timer information.

HEALTH
  Open the live System Health dashboard, with disk, system information,
  cooling and battery views. Unsupported measurements are unavailable,
  not proof that the hardware is healthy.

TIME
  Display system timer ticks and elapsed-time information, not wall-clock time.

DATE
  Placeholder: reports that an RTC driver is required for the real date.

DISKCHECK / CHKDSK
  Inspect hard-disk detection and native boot layout, including MBR/VBR
  information. This is a diagnostic, not a filesystem repair utility.


3. INTEILISHELL: FILES AND DIRECTORIES
------------------------------------

DIR / LS
  Display the native shell's demonstration directory listing.

DIR USB0:\ [or DIR USB0:\FOLDER]
  List actual contents of a mounted USB directory. USB1:, USB2: and USB3:
  can be used instead when mounted.

CD / CHDIR
  Display the shell's working-directory path.

CD <folder> / CHDIR <folder>
  Update the shell's working-directory path. CD .. goes up; CD \ returns
  to the root. This does not validate that the native directory exists.
  USB paths cannot become the working directory; use DIR USBn:\PATH.

TYPE <filename>
  Display a placeholder for native file contents.

TYPE USB0:\FILE.TXT
  Display a real text file from a mounted USB drive.

MKDIR <dirname> / MD <dirname>
  Placeholder: report directory creation without creating a native directory.
  USB directory creation is not supported by this command.

COPY <source> <destination>
  With a USB source or destination, copy a selected file using the supported
  USB/native storage paths. For example:
    COPY USB0:\NOTES.TXT C:\NOTES.TXT
    COPY C:\NOTES.TXT USB0:\NOTES.TXT
  Native-to-native use is a placeholder, not an actual copy.

MOVE <source> <destination>
  Placeholder for native files. USB moves are rejected; use COPY instead.

DELETE <filename> / DEL <filename> / ERASE <filename>
  Placeholder for native deletion. USB deletion is not supported here.

TREE
  Display a demonstration directory tree beneath the shell's current path.

FM / FILEMAN / FILEMANAGER
  Open InteiliFile Manager, the graphical file-browser application.
  Its displayed entries should not be treated as a complete saved-file index.


4. INTEILISHELL: USB STORAGE
---------------------------

USB
  Show USB command usage.

USB /?
  Also show USB usage. This option belongs to USB, not CDROM.

USB /MOUNT
  Detect and mount supported USB storage for reading and writing.
  FAT and exFAT are supported subject to controller and filesystem limits.

USB /SHOW-PORTS
  List currently mounted USB drives and their capacities. Names such as
  USB0: identify mounted volumes, not physical USB sockets.

USB /COPY
  Open the picker to choose one file and its save destination.
  This does not copy every file on the drive.

USB /FORMAT [USBn: [FAT16|FAT32|EXFAT]]
  Choose one mounted USB drive and its filesystem, then type the required
  FORMAT USBn: confirmation. Erases all files and partitions on that drive.
  FAT16: 8 MiB to 2 GiB; FAT32: at least 64 MiB; exFAT: at least 8 MiB.
  Quick format, not secure erasure. Enter/Esc cancels an unanswered prompt.
  Keep the drive connected once formatting starts. On success it is flushed
  and remounted read/write. Native HDD paths are never accepted.

USB /EJECT
  Flush and safely disconnect detected USB storage. Do not remove a drive
  if flushing or safe removal fails. USB keyboard operation is preserved.

USB paths use the form USB0:\FOLDER\FILE.TXT. Mount the drive before use.
Applications can also save to USB through their own save dialogs.


5. INTEILISHELL: CD-ROM
----------------------

CDROM
  Show CD-ROM command usage without probing the drives.

CDROM /DRIVE-INFO
  Refresh and display detected IDE ATAPI or SATA/AHCI optical drives,
  readable-disc capacity and ISO9660 volume information.

CDROM /LIST
  List ISO9660 root-directory entries on readable inserted data discs.
  The listing is limited to 64 entries per disc.

CDROM /RUN
  Open LaunchPad's CD-only browser to choose a native ELF program.
  Folders remain browsable; other file types are hidden.

CDROM /EJECT
  Request tray opening on the first drive with a readable disc, or the
  first detected drive if no readable disc is inserted.

CDROM /? is not supported. Use CDROM for usage.
Disc information and directory listings are read-only.


6. INTEILISHELL: APPLICATIONS, SPEECH AND DEMONSTRATIONS
------------------------------------------------------

IEDIT / EDIT
  Open the full-screen IEdit text editor.

WRITER / INTEILIWRITER / DOCS
  Open inteiliWriter, the built-in word processor. Left/right arrows move
  through text; up/down move through wrapped screen rows.
  F1 new document, F2 save TXT/Markdown, F3 load TXT/Markdown, F4 delete the
  current logical line, F5 export USB TXT, F6 export USB Markdown, F7 export
  USB PDF, F8 toggle bold, F9 toggle italic, F10 quit.
  Bold/italic apply to subsequently typed text; both can be on together.
  Markdown save/load and PDF export preserve formatting; TXT is plain text.
  Modified documents require confirmation before discard.
  Mount USB first with USB /MOUNT. Exports ask for a filename and mounted
  USB drive; explicit USB0:\DOC.TXT paths are also accepted.

SHEETS / ISHEETS
  Open InteiliSheets, including its SUM and AVG formula support.

BASIC / IBASIC
  Open inteiliBASIC. See sections 11-15 below.

PROGRAM / LAUNCHPAD
  Open LaunchPad to browse and load native ELF programs from supported
  CD-ROM, floppy and mounted USB sources.

TALK <text> / ITALK <text>
  Speak the supplied text using SAM text-to-speech through the PC speaker.

VOLUME / VOL
  Display the current PC-speaker volume.

VOLUME <0-100> / VOL <0-100>
  Set speaker volume. A percent sign is accepted, for example VOLUME 85%.
  Zero mutes speaker output.

TETRIS
  Start Tetris with keyboard and supported USB-gamepad controls.

DEMO
  Start the inteiliDOS feature showcase.

DAISY
  Show the IBM 7094-style presentation and play Daisy Bell.

GLADOS
  Play the Want You Gone presentation with black lyrics on an amber screen.


7. INTEILISHELL: MS-DOS EMULATOR
------------------------------

MS-DOS
  Enter the MS-DOS 6.22 emulator using available supplied boot media and
  the persistent private DOS C: disk. Required DOS images are not included
  in the repository; users must supply them separately.

MS-DOS /CDROM
    Exposes the files/folders on an ISO 9660 game CD/DVD as read-only D:.
    Uses supported SATA/AHCI or IDE optical drives, not floppy IMG files.
    Install/save to virtual C:. May combine with /MOUSE and sound switches.
    Not MSCDEX/CD-audio emulation. Exit with F8 before changing the disc.

MS-DOS /FLOPPY
  Read user-supplied DOS boot media from physical floppy drive A:.

MS-DOS /IMAGE <CD-image-name>
  Select a floppy-image file from CD media for the emulator.

MS-DOS /USB
  Locate user-supplied DOS images on supported USB storage.

MS-DOS /USB USB0:
  Select the USB volume containing the supplied DOS images.
  USB1:, USB2: or USB3: may be used instead.

MS-DOS /USB USB0:\GAME.IMG
  Load a USB floppy-image file as the emulator's A: drive.

MS-DOS /USB USB0:\DISK1.IMG USB0:\DISK2.IMG [...]
  Supply up to eight game floppy images. F6 cycles them in the supplied
  order. Paths may refer to supported USB volumes.

While in the emulator:
  F6 - Swap supplied images.
  F7 - Select/reload physical floppy media.
  F8 - Exit back to inteiliShell.

MS-DOS /MOUSE
  Enable the built-in DOS mouse driver for this session with a PS/2 mouse
  or PS/2-compatible touchpad. No separate MOUSE.COM is needed.
  Combine with media options, for example:
    MS-DOS /USB USB0:\GAME.IMG /MOUSE
  The switch is case-insensitive. Native USB mice are not supported.
  Without /MOUSE the built-in mouse driver remains disabled.
  The emulator's pointer starts hidden. With the driver active, F12 toggles
  its visibility; movement and clicks continue while hidden. Modified F12
  shortcuts still reach DOS. F12 works normally without an active driver.

The above are host commands and emulator controls, not MS-DOS's own
command reference. Commands typed at the emulated DOS prompt are handled
by the separately supplied DOS system. Disk reading is a work in progress.


8. INTEILISHELL: INSTALLATION AND BOOT MAINTENANCE
------------------------------------------------

SETUP / INSTALL-OS
  Open the inteiliDOS HDD/CompactFlash installation wizard.
  Setup is disabled on a successfully installed target HDD.
  Installation can erase or replace disk contents; read its confirmations.

BOOTREPAIR
  Start the confirmed native boot-sector repair flow, preserving saved
  files. Takes no arguments. Review the selected disk before approving.


9. INTEILISHELL: RECOGNIZED PLACEHOLDER UTILITIES
-----------------------------------------------

These commands are recognized but do not implement the advertised operation.
Do not use their messages as evidence of installation, backup or file changes.

INSTALL <package>
  Simulate searching, downloading and installing a package.

REMOVE <package>
  Simulate package removal.

UPDATE <package|ALL>
  Display simulated update-check results.

SEARCH <query>
  Display demonstration package-search results, not a live repository query.

BACKUP [target]
  Simulate creating an archive; defaults to the current directory.

RESTORE [backup]
  Simulate restoration; defaults to "latest".

FORMAT <drive>
  Display an erase warning; formatting is not implemented by this command.

LABEL <name>
  Report a volume-label change without actually changing the disk label.

SCRIPT <file.ish>
  Report the requested script; the script engine is not implemented here.

RUN <program>
  Display a launch message; this is not the functioning native program
  loader. Use PROGRAM or LAUNCHPAD to load native programs.

RUN /DOS <program>
  Explain that DOS programs must now be run inside MS-DOS; does not launch
  the supplied program.


10. INTEILISHELL: PLAIN-ENGLISH SHORTCUTS
----------------------------------------

The shell also translates these phrases to ordinary commands:

  show files / list files / show directory / list directory /
    what's here / what is here                         -> DIR
  where am i / current directory / pwd                 -> CD
  clear screen / clear the screen                     -> CLS
  i need help / what can i do / show commands /
    list commands                                     -> HELP
  how much memory / show memory / check memory         -> MEM
  system info / show system                           -> SYSINFO
  about this                                          -> ABOUT
  turn off / power off / shut down / shut it down      -> SHUTDOWN
  reboot / restart the computer                       -> RESTART
  quit / go back / return to shell                     -> QUIT
  make a folder named <name> / create a folder named
    <name> / make folder named <name> /
    create folder named <name>                         -> MKDIR <name>
  remove <name>                                       -> DELETE <name>
  download <package>                                  -> INSTALL <package>
  go to <folder> / go to folder <folder>               -> CD <folder>

The translation inherits the target command's limitations. For example,
translated MKDIR and INSTALL operations are still placeholders.


11. INTEILIBASIC: PROGRAM ENTRY AND SESSION COMMANDS
---------------------------------------------------

Start BASIC with BASIC or IBASIC at the shell. Keywords are case-insensitive.
Commands without line numbers execute immediately; numbered lines are stored.
This interpreter is integer BASIC, not a full QBasic implementation.

<line-number> <statement>
  Store or replace a program line, for example 10 PRINT "Hello".

<line-number>
  Delete that numbered program line.

HELP
  Display BASIC's built-in reference.

RUN [line-number]
  Run the stored program, optionally beginning at a selected line.

LIST [from[-to]]
  Display program lines. LIST shows all lines; LIST 100 starts at 100;
  LIST 100-200 shows the specified inclusive range.

NEW
  Clear the stored program and reset interpreter state.

CLS
  Clear the display.

DEMO <1-4>
  Replace the stored program with an example:
    1 Fibonacci; 2 number guessing; 3 times table; 4 strings.
  Use LIST to inspect it and RUN to execute it.

BYE / QUIT
  Leave BASIC and return to inteiliShell.


12. INTEILIBASIC: SAVING, LOADING AND CASSETTE
--------------------------------------------

SAVE
  Prompt for a filename and storage device, then save the program as text
  (.txt or .bas). Supported choices include C:, D: and mounted USB storage.

LOAD
  Prompt for a filename and device, then load the saved program.

CSAVE
  Encode the program as cassette audio through the PC speaker or supported
  USB audio output. Follow the recorder and ENTER prompts.

CLOAD
  Decode a cassette program through a supported USB audio adapter's input.
  Follow the playback prompts.

SAVE and LOAD use their dialogs, not SAVE "name" or LOAD "name" syntax.
Cassette operations require the appropriate audio hardware and connections.


13. INTEILIBASIC: OUTPUT, VARIABLES AND DATA
-------------------------------------------

PRINT <expression>[;<expression>][,<expression>] / ? <expression>
  Print numbers or strings. Semicolons join output; commas separate fields.

INPUT ["prompt";] <variable>[,<variable>...]
  Read values into numeric or string variables.

LET <variable> = <expression>
  Assign a numeric or string value. LET is optional: A = 5 also works.

DIM A(<size>)
  Allocate a numeric array. Array subscripts run from 1 to the declared size.

DATA <value>,<value>,...
  Store numeric or string constants for READ.

READ <variable>[,<variable>...]
  Read the next DATA values into numeric or string variables.

RESTORE
  Reset the DATA reading position to the beginning.

SWAP <variable1>,<variable2>
  Exchange the values of two variables of the same type.

REM <comment>
  Mark the rest of the line as a comment. An apostrophe can also begin
  a comment.

Variables: A-Z are signed 32-bit integers; A$-Z$ are strings of up to
79 characters; A(n)-Z(n) are numeric arrays. Use a colon to separate
statements on one line.


14. INTEILIBASIC: FLOW CONTROL AND LOW-LEVEL STATEMENTS
------------------------------------------------------

IF <condition> THEN <statement-or-line> [ELSE <statement-or-line>]
  Execute the matching branch according to the condition.

GOTO <line-number>
  Jump to a program line.

GOSUB <line-number>
  Call a program subroutine.

RETURN
  Return from the most recent GOSUB.

FOR <variable> = <start> TO <end> [STEP <increment>]
  Begin a counted loop.

NEXT [variable]
  Advance the loop variable and repeat or finish the loop.

ON <expression> GOTO <line1>,<line2>,...
  Choose a destination by a one-based numeric index.

ON <expression> GOSUB <line1>,<line2>,...
  Choose and call a subroutine by a one-based numeric index.

END / STOP
  Stop execution and return to the BASIC prompt. There is no CONT command.

POKE <address>,<value>
  Write a byte directly to memory. Unsafe addresses can corrupt the OS
  or crash the machine; this is not sandboxed.

BEEP
  Accepted but currently does nothing; it does not produce a tone.

Operators:
  + - * / MOD     Integer arithmetic (and + for string concatenation).
  = <> < > <= >=  Comparisons.
  AND OR NOT      Logical/bitwise expression operations.
  Parentheses     Group expressions.


15. INTEILIBASIC: FUNCTIONS
---------------------------

Numeric functions:

ABS(n)              Absolute value.
SGN(n)              Sign: -1, 0 or 1.
INT(n)              Return n unchanged; all numeric values are integers.
RND(n)              Pseudorandom integer 1 through n; returns 0 for n <= 0.
LEN(s$)             Number of characters in a string.
VAL(s$)             Convert a numeric string to an integer.
ASC(s$)             Character code of the first character, or 0 if empty.
POS(0)              Current BASIC output-column counter.
FRE(0)              Placeholder: always returns 131072, not actual free RAM.
PEEK(address)       Read a byte directly from memory. Unsafe addresses can
                    fault or access hardware; use with extreme care.

String functions:

CHR$(n)             One character with the supplied character code.
STR$(n)             Integer converted to a string.
LEFT$(s$,n)         First n characters.
RIGHT$(s$,n)        Last n characters.
MID$(s$,pos[,len])  Substring beginning at one-based pos; optional length.
INKEY$             Poll for a printable key; empty string if none is available.
INPUT$(n)           Read up to n printable characters from the keyboard.
SPACE$(n)           String of n spaces.
STRING$(n,c$)       Repeat the first character of c$, n times.

PRINT formatting helpers (used within PRINT, not general expressions):

TAB(n)              Output spaces until the output-column counter reaches n.
SPC(n)              Output n spaces, up to the PRINT column limit.

Function output remains subject to the interpreter's string-size limits.
